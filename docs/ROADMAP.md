# Roadmap

The focus is a reliable standalone planetary-battle game for Windows.

## Reliable battles

- Consistent robot construction, movement and combat behavior.
- Safe configuration loading and storage with compatible data formats.
- Usable controls, readable interface text and standalone sound.
- Reliable startup, battle completion and shutdown.
- Recovery from supported window and graphics-device transitions.

## Development and delivery

- Reproducible builds and straightforward setup instructions.
- Regression tests using synthetic data and reproducible simulation scenarios.
- Clear subsystem boundaries and documentation of resource formats and ownership.
- Repeatable binary packaging with the required notices and runtime guidance.

The [build guide](BUILD_WINDOWS.md), [testing guide](TESTING.md) and
[contribution guide](../CONTRIBUTING.md) describe the development procedures.

## Longer term

Broader platform support and tools for new content can follow once the Windows
game provides a reliable foundation.
